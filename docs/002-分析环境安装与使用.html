2  Installing and Using the Analysis Environment

This chapter explains how to set up an ivdtools analysis environment, create a qmd project, import and verify data, run progressive analyses, and save reproducible results.

2.1 Install R

ivdtools requires R >= 4.1.0. We recommend using a newer R version that is still supported and keeping the major versions of R and all dependencies consistent across everyone working on a project.

2.1.1 Windows and macOS

Download the installer for your operating system from CRAN: https://cran.r-project.org/.

  • Windows: install R. A matching version of Rtools is needed only when compiling packages containing native code from source.
  • macOS: choose the installer for your processor architecture. Xcode Command Line Tools may be needed when compiling from source.

2.1.2 Debian/Ubuntu

The system repository can install the base R environment:

sudo apt update
sudo apt install r-base r-base-dev

2.1.3 Fedora

sudo dnf install R R-devel

R versions in Linux distribution repositories may be old. If a project needs a newer R version, configure the repository by following the instructions for the relevant distribution on CRAN.

2.2 Choose an Editor

We recommend using .qmd or .Rmd files to record code, text, tables, and figures.

RStudio and Positron are available from https://posit.co/downloads/; Visual Studio Code is available from https://code.visualstudio.com/Download.

2.3 Install R Packages

When ivdtools has been published to the CRAN mirror you use:

Code 
install.packages(c("ivdtools", "rmarkdown", "knitr"))

Install optional packages for data import as needed:

Code 
install.packages(c("readr", "readxl"))

2.4 Create a Project

In RStudio, choose File > New File > R Markdown.

Minimal document template:

---
title: "IVD Analysis Report"
author: "Analyst"
date: "Enter report date"
output:
  html_document:
    toc: true
    number_sections: true
---

2.5 Import and Verify Data

2.5.1 CSV

Base R:

Code 
dat <- read.csv(
  "data-raw/method-comparison.csv",
  stringsAsFactors = FALSE,
  check.names = FALSE
)

Using readr:

Code 
dat <- readr::read_csv(
  "data-raw/method-comparison.csv",
  show_col_types = FALSE
)

2.5.2 Excel

Code 
dat <- readxl::read_excel(
  "data-raw/method-comparison.xlsx",
  sheet = "data"
)

If an Excel file contains formulas, merged cells, or manual formatting, first confirm that the imported values, column names, and data types agree with the original table.

2.6 Run Code

Insert an R code block in an .Rmd file and use the button in the upper-right corner of the block to run it, or run all code from top to bottom.

For reproducibility, the final report should be rendered from start to finish in a fresh R session rather than relying only on objects already present in the Console.

2.7 Export Results

2.7.1 Tables

After reading the result fields described in the relevant help page, write a table to disk as CSV:

Code 
# Example: confirm the actual field in the relevant object help page
result_table <- mc$regression
saveRDS(result_table, "tables/regression-result.rds")

Prefer saving complex objects as RDS to preserve their classes and attributes. When exchanging results with other software, first organize the object as a flat data frame and then export it as CSV.

2.7.2 Figures

All figures are drawn with ggplot.

Code 
p <- plot(mc, type = "bland_altman")
ggplot2::ggsave(
  "figures/bland-altman.png",
  plot = p,
  width = 7,
  height = 5,
  dpi = 300
)

2.8 Render and Save

In RStudio, click Knit, or run:

Code 
rmarkdown::render(
  "report/analysis.Rmd",
  output_format = "html_document",
  clean = TRUE
)

Record environment information after completing the analysis:

Code 
sessionInfo()
