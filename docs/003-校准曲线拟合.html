3  Calibration Curve Fitting

This chapter demonstrates how to use fit_equation() from ivdtools to fit calibration curves and check convergence, residuals, the effect of weights, and forward and inverse predictions. The underlying implementation calls minpack.lm, nloptr, nls2, and stats.

Code 
library(ivdtools)
library(readr)

3.1 Main Functions

Function Purpose
list_equation() View the built-in equation registry
replicate_to_mean() Summarize replicate measurements and optionally calculate weights
fit_equation() Fit a built-in or custom equation
coef() Extract model parameters
residuals() Extract observed-minus-fitted residuals
predict() Predict response values forward or estimate concentrations inversely
plot() Plot observed points, the fitted curve, and intervals
compare_equation() Compare candidate equations

The function returns a registry data frame containing equation IDs, names, formulas, numbers of parameters, applicable categories, and fitting engines.

3.1.2 Summarize Replicates with replicate_to_mean()

If each concentration has replicate measurements, you can fit all observations directly or first summarize them with replicate_to_mean().

Code 
replicate_to_mean(
  data, x = "Con", y = "RLU", weights = NULL, na.rm = TRUE
)

The function groups by x and returns summary fields such as the mean, number of replicates, and dispersion at each concentration. weights can provide numeric weights or a weighting rule for later fitting. na.rm = TRUE excludes missing rows; the number excluded should be recorded. Summary means are suitable for describing each level and should not automatically be treated as the error model for a future single specimen.

3.1.3 Fit a Built-in or Custom Equation with fit_equation()

fit_equation() accepts an ordinary data.frame. x is the concentration or relative concentration and y is the instrument response; both columns must contain finite numeric values.

fit_equation() can use automatic starting values or starting values supplied through start; lower, upper, and constraints can set parameter bounds or constraints. weights accepts a numeric vector or one of the built-in schemes "equal", "1/y", "1/y^2", "1/x", and "1/x^2".

Code 
fit_equation(
  eq, data, x = "x", y = "y", start = NULL,
  lower = NULL, upper = NULL, constraints = NULL,
  weights = NULL, ...
)

The returned object has S3 class fit_equation and contains the selected equation, fitted model, parameters, data, and fitting diagnostics.

3.1.4 Compare Candidate Equations with compare_equation()

Main inputs

Code 
compare_equation(
  data, x = "Con", y = "RLU", eqs = c("4PLC", "5PLC")
)

The returned object has S3 class compare_equation; its $table is sorted by AIC and includes at least Eq, Name, Formula, nPar, AIC, deltaAIC, R2, and RSE. AIC is evidence for comparing candidate models, not a replacement for residuals, plateau behavior, the reporting range, or external validation. If candidate models were not prespecified in the protocol, the comparison should be labeled exploratory.

3.1.5 Get Fitted Parameters and Residuals with coef() and residuals()

Code 
coef(fit)
residuals(fit)

Here fit is the fitted object returned by fit_equation(). coef(fit) returns a named vector of fitted coefficients; residuals(fit) returns observed-minus-fitted residuals corresponding to valid observation rows.

3.1.6 Forward Response Prediction or Inverse Concentration Estimation with predict()

Code 
predict(
  fit,
  newdata,
  interval = "confidence",
  level = 0.95,
  inverse = TRUE
)

newdata contains the concentrations or responses to predict. interval and level specify the interval type and confidence level. A confidence interval describes uncertainty in the fitted mean; a prediction interval also includes single-observation error and is usually wider. inverse requests inverse estimation of concentration from response.

The function returns a data frame containing input values, point predictions, and the requested lower and upper bounds. For inverse prediction, the point prediction is the estimated concentration.

ImportantPrediction Boundaries

Avoid extrapolating beyond the calibration concentration range. Inverse prediction is highly sensitive to response error on a plateau, and non-monotonic models may have multiple solutions.

3.1.7 Plot the Fitted Curve and Interval with plot()

Code 
plot(fit, interval = "confidence", level = 0.95)

Use the figure to check observed points, the fitted curve, intervals, and the calibration range. A formal report should preserve the equation, weights, interval type, parameters, convergence status, and plotting parameters.

3.2 Analysis Examples

3.2.1 Fitting a Linear Calibration Curve

The linear equation is appropriate when the response changes with concentration at an approximately constant rate across the working range. In the ivdtools registry it corresponds to E01:

\[y = a + b x\]

Here \(a\) is the intercept and \(b\) is the slope. This example uses deterministic teaching data in data/003-校准曲线拟合/Linear.csv only to demonstrate the workflow. A formal calibration should define the concentration range, number of replicates, weights, and acceptance criteria in the study protocol.

Code 
# Read the linear data file
fit_linear_data <- read_csv(
  "./data/003-校准曲线拟合/Linear.csv",
  show_col_types = FALSE
)

# Inspect the data structure

Assess model suitability using residual trends, fitted intervals, back-calculated bias, and prespecified acceptance criteria; a high \(R^2\) alone does not establish complete linearity across the calibration range. Inverse predictions should be restricted to the actual calibration range and should not be extrapolated without justification.

3.2.2 Fitting a 4PLC Calibration Curve for a Sandwich Assay

The four-parameter logistic (4PLC) model is nonlinear:

\[y = A + \frac{B-A}{1 + (x/C)^D}\]

Here \(A\) and \(B\) are the two asymptotic plateaus, \(C\) is the concentration scale at the midpoint of the curve, and \(D\) controls the direction and steepness. Interpret the parameters in light of the actual signal direction.

Code 
# Read the data file
fit_4plc_data <- read_csv("./data/003-校准曲线拟合/4PLC.csv", show_col_types = FALSE)

# Inspect the data structure

3.2.3 Constrained Fitting

The following example reuses the linear data above and focuses on how to specify parameter constraints in fit_equation().

When theory says that the response should be 0 at concentration 0, or when the protocol explicitly requires that the intercept not be estimated, the intercept parameter \(a\) can be fixed at 0:

Code 
fit_linear_zero <- fit_equation(
  "E01",
  data = fit_linear_data,
  x = "Con",
  y = "RLU",
  constraints = list(eq = function(p) p["a"])
)

print(fit_linear_zero)
