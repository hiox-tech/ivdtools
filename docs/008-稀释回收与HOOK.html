8  Dilution Recovery, Spike Recovery, and Hook Effect

This chapter covers three related but distinct analyses: dilution recovery, spike recovery, and high-dose hook effect. Each uses a different expected-value calculation and requires its own acceptance limits.

Path Main input Main result
Dilution recovery Sample ID, result, dilution factor, optional assignment Target, dilution-corrected concentration, per-sample and across-sample recovery
Spike recovery Spiked and solvent-control results, theoretical added concentration Observed increment and recovery
High-dose hook effect Known concentration, raw response, ULoQ, optional series Concentration summaries, hook-effect boundary, or lower bound when no hook is observed
ImportantScope of Use

Recovery and hook-effect calculations do not by themselves establish an extended measuring interval. Interpret them together with precision, LoQ, specimen commutability, carryover, and prespecified acceptance limits. Use raw instrument response for hook-effect analysis; reported concentrations may already be truncated.

8.1 Main Functions

Function Purpose Return value
dilution_recovery() Calculate dilution targets, corrected concentrations, and recovery dilution_recovery object
spike_concentration() Calculate theoretical post-spike concentration by mass balance Data frame
spike_recovery() Calculate recovery relative to solvent control spike_recovery object

8.1.1 Dilution Recovery

Code 
dilution_recovery(
  data, sample, result, dilution_factor, assigned = NULL,
  diluent_value = 0, conf.level = 0.95
)

dilution_factor is 1 for undiluted material and 2 for a 1:2 dilution. If assigned is omitted, the mean of each sample’s undiluted results is used as the original concentration. The target after dilution is

\[C_{target}=\frac{C_{assigned}}{d},\]

and the corrected concentration is \(dC_{measured}\) when the diluent contains no analyte. Report the dilution-level and across-sample recovery, not only a pooled mean.

8.1.2 Theoretical Spike Concentration

Code 
spike_concentration(
  sample_concentration, sample_volume,
  stock_concentration, spike_volume
)

By mass balance,

\[C_{final}=\frac{C_sV_s+C_{stock}V_{spike}}{V_s+V_{spike}}.\]

8.1.3 Spike Recovery

Code 
spike_recovery(
  data, sample, result, condition,
  analyte_level, solvent_level, added_concentration = NULL,
  sample_volume = NULL, stock_concentration = NULL, spike_volume = NULL,
  conf.level = 0.95
)

The observed increment is the spiked result minus the solvent-control result. Recovery is the observed increment divided by the theoretical added concentration. Supply added_concentration directly or let the function calculate it from volumes and stock concentration.

8.1.4 High-Dose Hook Effect

Code 
hook_effect(
  data, concentration, response, series = NULL, uloq,
  uloq_response = NULL, conf.level = 0.95
)

The input must contain known concentrations and raw responses. series identifies independent hook-effect series. If uloq_response is omitted, every series must contain a record at concentration == uloq. The function summarizes response at each concentration, compares it with the ULoQ reference, and reports an observed hook boundary or the lower bound supported when no hook is observed.

8.3 Interpretation

Recovery near 100% does not prove accuracy across the entire interval; bias can vary with concentration and matrix. A lack of observed hook effect means only that the tested concentrations and responses support a lower bound. The EP34 Tables 1–8 and Appendix C files supplied with the project can be used for reproducible cross-checks, but the standard’s final measuring-interval decision still requires all relevant evidence and prespecified limits.
