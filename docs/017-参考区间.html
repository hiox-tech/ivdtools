17  Reference Intervals

This chapter introduces reference-interval establishment, method selection, and result reporting. A reference interval describes the distribution range of measurements in a target reference population. It is not a disease-diagnostic cutoff and does not automatically apply to populations with different age, sex, region, or measurement system; population definitions and inclusion/exclusion criteria must be reported with the statistical method.

ImportantScope of Use

reference_interval() calculates a statistical interval for a defined sample set. It does not recruit reference individuals, determine partitions, justify sample size, investigate causes of outliers, or validate transfer across systems. Detection by an outlier test is not an automatic reason for exclusion, and a normality test does not replace a distribution plot. Reference coverage interval and endpoint confidence level ci are different parameters.

Workflow: establish and interpret a reference interval

A reference interval (RI) is defined by measurements in a reference sample population and is used to interpret individual results, corresponding to CLSI EP28-A3c. ivdtools uses the standard simple nonparametric method by default and implements the Appendix B biweight method. It also provides R type-6 quantiles with normal-approximation rank intervals, normal/log-normal parametric intervals, and Huber M robust intervals as explicitly named extensions. These methods differ in sensitivity to sample size, distribution shape, and outliers. Perform outlier and normality assessment before establishment; presenting multiple methods is a sensitivity comparison, not a post hoc choice of the most favorable result.

library(ivdtools)
library(readr)

Function Main purpose Key inputs or outputs

Code 
reference_interval(
  data, col, interval = 0.95, ci = 0.95,
  method = "nonparametric",
  id = NULL,
  bootstrap_replicates = 1999,
  seed = NULL
)

Let the central coverage be \(γ\). The two-tail probability is

\[ \alpha=(1-γ)/2. \]

The five methods are defined as follows:

Method Reference limits Endpoint interval
nonparametric (default) EP28 \(r=p(n+1)\) with linear interpolation at noninteger ranks Order-statistic interval from binomial inversion, with actual coverage reported
biweight EP28 Appendix B \(T_{bi}\), \(s_{bi}[205.6]\), and \(S_T[3.7]\) Percentile bootstrap
type6 R quantile(type=6) at \(α\) and \(1-α\) Retained normal-approximation rank positions
parametric \(̅x±z_{1-α}s\) t approximation for the SE of reference limits
huber Huber location \(T±z_{1-α}S\) Percentile bootstrap

The parametric method first performs Shapiro–Wilk. If normality is rejected and all values are positive, it tries a natural-log transformation; only if normality is not rejected after transformation does it calculate on the log scale and back-transform. If both original and log scales reject normality, the function warns and continues on the original scale. Biweight and Huber both start from the median and MAD, but use different weights, scales, and reference-limit formulas; they must not be treated as one generic “robust method.” bootstrap_replicates must be at least 100. Setting seed makes the bootstrap reproducible, and the function restores the caller’s random-number state.

Complete finite values in col enter the analysis; id is used only to report duplicate rows and does not automatically retain one row per person. The object stores nonparametric, biweight, type6, parametric, and huber results along with cleaned values. Showing all five methods is a sensitivity comparison, not a license to choose the most favorable method after seeing results.

outliers_test() and normal_test() return the method, statistic, P value, and indices. reference_interval() returns reference limits, endpoint confidence intervals, actual coverage, and cleaned data. plot.reference_interval() returns a ggplot object.

17.2 Analysis Examples

17.2.1 Example: Compare All Five Methods

This example performs prespecified outlier and normality checks and then calls reference_interval(method = "all") to output all five methods. The deterministic teaching data have \(n=120\), mild right skew, and outliers.

Code 
ri_data <- read_csv("./data/017-参考区间/reference-interval.csv", show_col_types = FALSE)
ri_data <- as.data.frame(ri_data)

EP28 recommends reviewing outliers before establishing an RI. With \(n=120\), Dixon is not suitable (it is limited to \(n\le30\)), so use Grubbs and generalized ESD:

In reference_interval(), interval is reference-interval coverage (default 0.95, corresponding to 2.5%–97.5%) and ci is endpoint confidence level; they have different meanings. method can be any combination of "nonparametric", "biweight", "type6", "parametric", and "huber", or the single value "all". id is used for duplicate-sample detection.

The five methods in this example are:

  • Nonparametric (73.4–157.6): EP28 point estimates make no distributional assumption and endpoint CIs use binomial ranks.
  • Biweight (63.3–141.7): uses the two scale components from EP28 Appendix B; this teaching data set with outliers does not satisfy the prerequisite of investigating anomalies first.
  • Type 6 (73.4–157.6): point estimates match the nonparametric method, but endpoint CIs use retained normal-approximation ranks.
  • Parametric (73.3–145.9): after detecting non-normality, the function applies a log transformation (transformed=TRUE) and back-transforms.
  • Huber (72.2–134.7): based on Huber M estimation and MAD.

Differences among methods reflect different rank intervals, distributional assumptions, and robust-scale definitions.

17.2.2 Standard Case: CLSI EP28-A3c Appendix B Robust Iteration

Appendix B demonstrates the biweight calculation with 20 female calcium observations. This small sample is for algorithm demonstration only; the standard explicitly does not recommend it for establishing a formal RI. method="biweight" directly returns the location, scale components, reference limits, and bootstrap endpoint intervals from Appendix B.

Code 
ep28_b <- as.data.frame(read_csv(
  "./data/017-参考区间/std-ep28-appendix-b.csv",
  show_col_types = FALSE
))
ep28_biweight <- reference_interval(
  ep28_b, col = "calcium", interval = 0.95,
  ci = 0.90, method = "biweight",
  bootstrap_replicates = 1999, seed = 2803
)
