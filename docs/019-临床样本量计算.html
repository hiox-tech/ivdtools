19  Clinical Sample-Size Calculation

Sample size is determined by effect size, variability, confidence level, power, and study design; it is not a fixed constant. This chapter covers the three sample-size problems implemented by ivdtools: Bland–Altman agreement precision/power, precision of a single-proportion confidence interval, and a one-arm test of a proportion against a target.

ImportantScope of Use

The functions do not add attrition, invalid samples, minimum numbers per stratum, design effects, clustering, or multiplicity adjustments. delta in a Bland–Altman calculation is the clinically acceptable limit, not the observed LoA. Confidence-interval methods and one- or two-sided directions must be prespecified. Preserve all assumptions and sensitivity analyses, not only the final integer.

Code 
library(ivdtools)

19.1 Main Functions

Function Main purpose Solving direction
sample_size_bland_altman() Bland–Altman agreement evaluation Solve for n from target power
sample_size_proportion_ci() Single-proportion confidence interval Solve for n from the target half-width
sample_size_proportion() One-arm target-value test Solve for n from the target alpha and power

All three functions are parameter-driven and do not require raw data. They return structured results; the sample size is in result$n, and print() shows target and achieved quantities. Round-up, attrition, invalid samples, and minimum stratum counts must be handled separately.

19.1.1 Interfaces

Code 
sample_size_bland_altman(
  power = 0.80, mu, sd, delta,
  conf.level = 0.95, agree.level = 0.95,
  method = "lu", n.min = 3, n.max = 1e5
)
sample_size_proportion_ci(
  p, half_width, conf.level = 0.95,
  interval = c("two.sided", "lower", "upper"),
  method = "wilson", n.max = 1e6
)
sample_size_proportion(
  p0, p1, alpha = 0.05, power = 0.80,
  alternative = c("greater", "less", "two.sided"),
  test = "exact", power_method = "binomial", n.max = 1e6
)

For Bland–Altman, the target LoA are

\[ \mu\pm z_{(1+\gamma)/2}\sigma, \]

where $γ=agree.level. The function uses the Lu et al. noncentral-t calculation for the probability that both LoA confidence bounds remain within \(±\delta\) and searches for the smallest integer meeting target power. It requires \(δ>|\mu|+z_{(1+γ)/2}σ\).

For a proportion interval, the target is a half-width \(d\). For two-sided intervals,

\[\frac{U-L}{2}\le d,\]

and for one-sided intervals the distance from the expected proportion to the relevant limit is at most \(d\). The interval method affects the required sample size and must be stated in the protocol.

For a one-arm test, test determines the rejection region and power_method chooses continuous normal planning or discrete binomial enumeration. The final integer sample size is checked using actual alpha and achieved power; binomial planning additionally controls actual alpha rather than relying on an approximation.

Code 
n_sp <- sample_size_proportion(
  p0 = 0.2, p1 = 0.35, alpha = 0.05, power = 0.8,
  alternative = "greater", test = "exact", power_method = "binomial"
)
print(n_sp)

  Test                  : Exact binomial test
  Power calculation     : Binomial enumeration
  H0: p <= 0.2000
  H1: p > 0.2000

19.2.4 Standard and Guidance Cross-Checks

The supplied examples compare the functions with PASS, SAS, and CMDE calculations. Small differences can arise from continuous normal planning versus discrete binomial enumeration, exact quantiles versus rounded handbook quantiles, interval definitions, and integer search rules. For example, a handbook may report a rounded approximate sample size while the package returns the first integer whose actual operating characteristics meet the stated constraint. Report both the selected method and achieved alpha/power.

19.3 Interpretation Checklist

  1. Define the primary endpoint, analysis unit, expected proportion or difference, allowable error, and tail direction.
  2. Run sensitivity analyses for uncertain SDs, proportions, prevalence, and agreement limits.
  3. Select interval and test methods before calculating the sample size.
  4. Add attrition, invalid-sample, stratification, clustering, and multiple-endpoint allowances outside these functions.
  5. Save parameters, function calls, outputs, and the software version in the protocol.

19.4.4 CMDE Appendix Case 1: Target-Value Method with Clinical Acceptance Criteria

The appendix uses the normal-approximation formula

\[ n=\frac{\left[Z_{1-\alpha/2}\sqrt{P_0(1-P_0)}+ Z_{1-\beta}\sqrt{P_T(1-P_T)}\right]^2}{(P_T-P_0)^2}. \]

The case uses two-sided alpha = 0.05 and power = 1 - beta = 0.80. The acceptable-standard/expected-value pairs are 85%/90% for positive agreement and 90%/94% for negative agreement. Using Z0.975 = 1.96 and Z0.80 = 0.84, the appendix reports 362 positive cases and 388 negative cases, for 750 total; after a 10% dropout allowance, at least 834 participants are enrolled.

sample_size_proportion(test = “score”, power_method = “normal”) performs the same continuous normal approximation. The package uses unrounded normal quantiles and rounds the theoretical result upward; actual alpha and power are then recalculated separately from the discrete binomial rejection region.

Code 
cmde_target_value <- data.frame(
  group = c("Positive group", "Negative group"),
  p0 = c(0.85, 0.90),
  p1 = c(0.90, 0.94),
  cmde_n = c(362L, 388L)
)

cmde_target_results <- lapply(
  seq_len(nrow(cmde_target_value)),
  function(i) {
    sample_size_proportion(
      p0 = cmde_target_value$p0[i],
      p1 = cmde_target_value$p1[i],
      alpha = 0.05,
      power = 0.80,
      alternative = "two.sided",
      test = "score",
      power_method = "normal"
    )
  }
)

19.4.5 CMDE Appendix Case 2: Allowable Error Method Requiring CI Precision

The appendix formula is

\[ n=\frac{Z_{1-\alpha/2}^2P(1-P)}{\Delta^2}. \]

The expected sensitivity is 85%, the expected specificity is 90%, and the allowable error is Delta = 0.05. This corresponds to sample_size_proportion_ci(method = “wald”). The package uses the exact qnorm(0.975) and rounds upward to the smallest integer satisfying the half-width requirement.

Code 
cmde_ci_precision <- data.frame(
  group = c("Positive group (sensitivity)", "Negative group (specificity)"),
  p = c(0.85, 0.90),
  cmde_n = c(196L, 138L)
)
cmde_ci_precision$ivdtools_n <- vapply(
  cmde_ci_precision$p,
  function(p) sample_size_proportion_ci(
    p = p, half_width = 0.05, conf.level = 0.95, method = "wald"
  )[["n"]],
  integer(1)
)
CMDE allowable-error method and 10% addition
Standard location Statistic Standard ivdtools
CMDE allowable-error / Positive group (sensitivity) sample size 196 196
CMDE allowable-error / Negative group (specificity) sample size 138 139
CMDE allowable-error / Total sample size 334 335
CMDE allowable-error / 10% addition enrolment 371 373

The package gives 139 for the negative group while the appendix reports 138. The difference has two causes: the appendix substitutes the approximate value 1.96 and reports 138.30 as 138, whereas the package uses the exact quantile and rounds upward. The appendix then reports 371 after adding 10% to 334 cases; if “at least enroll” is handled conservatively, the package’s 335 analyzable cases require ceil(335 / 0.90) = 373. This is a quantile-precision and integer-rounding difference, not a difference in the CI method.

When the expected proportion is close to 100%, the guidance also warns that the normal approximation may be unsuitable. Use sample_size_proportion_ci(method = “clopper-pearson”) or another method for sensitivity analysis, but label the result as a supplementary analysis under a different interval method rather than as a recalculation of the appendix’s Wald formula.
