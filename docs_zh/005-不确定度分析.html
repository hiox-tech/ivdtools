5  不确定度分析

本文演示如何使用 ivdtools 包建立测量不确定度分量、传播测量模型、合成不确定度预算，并沿计量溯源阶段汇总结果。内容覆盖 A 类和 B 类评价、长期 IQC、瓶间均匀性、稳定性、多实验室定值以及单节点和逐级预算。

重要使用边界

本文中的普通数据和标准案例数据仅用于验证分析流程。uncertainty_* 系列函数计算标准不确定度、合成不确定度和扩展不确定度，不替代被测量定义、实验设计、临床接受标准、法规评价或产品放行结论。正式报告必须说明被测量、单位、结果是单次值还是均值、各分量的来源、分布、自由度、覆盖因子和相关性假设。

标准案例的数值以标准原文为依据；每个案例均将 ivdtools 计算结果与标准原文结果逐项比较。标准原文的中间舍入、统计口径或近似方法与函数默认计算不同而产生的差异，会在对照表后单独说明。

测量不确定度分析首先明确输出量和测量模型，再把不同来源的信息转换为标准不确定度分量：

设输入量的标准不确定度为 \(u_i\)，灵敏度系数为 \(c_i\)，则在独立假设下，合成标准不确定度可表示为：

\[u_c = \sqrt{\sum_i (c_i u_i)^2}\]

有相关性时还应加入协方差项。扩展不确定度为：

\[U = k u_c\]

其中 \(k\) 为覆盖因子。relative = TRUE 保存相对标准不确定度；相对分量和绝对分量混合时，应向 uncertainty_combine() 提供结果量值 value。

代码 
library(ivdtools)
library(readr)

5.1 主要函数

函数 主要用途

uncertainty_type_b() 由证书、上下限或分布估计 B 类分量
uncertainty_iqc() 从长期 IQC 提取批内、批间和综合分量
uncertainty_homogeneity() 评价瓶间或单元间均匀性
uncertainty_stability() 由时间趋势估计货架期稳定性分量

5.1.1 重复测量的 A 类分量 uncertainty_type_a()

quantity = “single” 使用重复结果的样本标准差，描述未来单次结果；quantity = “mean” 使用标准误，描述这组重复结果的均值。二者对应的被报告量不同。

代码 
repeatability <- uncertainty_type_a(
  c(99.5, 100.2, 100.0, 99.8, 100.1),
  name = "重复测量",
  quantity = "mean",
  relative = TRUE
)

返回对象包含估计值、标准不确定度、相对标准不确定度、自由度、评价类型、分布和来源等字段。非有限值会被排除，但正式分析仍应保存原始数据和排除记录。

5.1.2 证书或规格的 B 类分量 uncertainty_type_b()

当证书直接给出扩展不确定度时，必须提供证书对应的 k；当只有上下限时，应根据证书、规格或科学依据选择分布。

代码 
certificate <- uncertainty_type_b(
  name = "校准品证书",
  estimate = 100,
  uncertainty = 2,
  distribution = "normal",
  k = 2,
  relative = TRUE
)

pipette <- uncertainty_type_b(
  name = "移液器容量",
  estimate = 10,
  lower = 9.9,
  upper = 10.1,
  distribution = "rectangular"
)

5.1.3 长期 IQC 分量 uncertainty_iqc()

有运行批次和批内重复时，函数使用单因素随机效应 ANOVA 分解批内和批间变异；没有 run 列或每个运行只有一个结果时，直接使用长期结果的离散程度。

代码 
iqc_data <- data.frame(
  run = rep(1:5, each = 2),
  result = c(99, 101, 100, 102, 98, 100, 101, 103, 99, 100)
)

iqc_component <- uncertainty_iqc(
  iqc_data,
  result = "result",
  run = "run",
  quantity = "single",
  name = "长期 IQC",
  relative = TRUE
)

iqc_component

  Runs                      : 5

IQC 水平应代表被报告结果的浓度水平。失控期间是否排除必须由预先规定的质量程序决定；如果 IQC 已包含某个校准或批间来源，不应把相同来源再次作为独立分量加入。

5.1.4 瓶间均匀性分量 uncertainty_homogeneity()

数据应为长格式，每个包装单元通常包含多次重复测量。函数返回均方、重复性标准差、观察到的单元间标准差、隐含不均匀性和最终的 u_bb。

代码 
homogeneity_data <- data.frame(
  bottle = rep(paste0("B", 1:4), each = 2),
  result = c(99, 100, 101, 100, 98, 99, 102, 101)
)

homogeneity_component <- uncertainty_homogeneity(
  homogeneity_data,
  unit = "bottle",
  result = "result",
  name = "瓶间均匀性",
  relative = TRUE
)

5.1.5 稳定性趋势分量 uncertainty_stability()

函数拟合：

\[result = intercept + slope \times time\]

目标货架期上的趋势不确定度为斜率标准误乘以货架期。shelf_life 与 time 必须使用同一时间单位。

代码 
stability_data <- data.frame(
  time = rep(0:4, each = 2),
  result = c(100.1, 99.9, 100.0, 99.8, 99.7,
             99.9, 99.6, 99.8, 99.5, 99.7)
)

stability_component <- uncertainty_stability(
  stability_data,
  time = "time",
  result = "result",
  shelf_life = 6,
  name = "6个月长期稳定性",
  relative = TRUE
)

stability_component

5.1.6 多实验室定值分量 uncertainty_characterization()

函数先计算每个实验室的均值，再对实验室均值等权汇总。某个实验室重复次数更多不会自动获得更大权重。

代码 
characterization_data <- data.frame(
  laboratory = rep(paste0("Lab", 1:4), each = 3),
  result = c(
    99, 100, 101,
    100, 101, 100,
    98, 99, 100,
    101, 102, 101
  )
)

characterization_component <- uncertainty_characterization(
  characterization_data,
  laboratory = "laboratory",
  result = "result",
  name = "多实验室定值",
  relative = TRUE
)

5.1.7 单节点合成 uncertainty_combine()

uncertainty_combine() 适用于组件已经表达在同一输出尺度的情况。sensitivity 表示输入变化对输出的局部影响；correlation 用于提供输入量之间的相关矩阵。默认相关矩阵为单位矩阵，即假设分量相互独立。

代码 
budget <- uncertainty_combine(
  repeatability,
  certificate,
  homogeneity_component$component,
  value = 100,
  coverage = 0.95,
  k = 2

5.1.8 非线性测量模型 uncertainty_propagate()

对于比值、乘积、幂函数、对数或其他非线性测量模型，可用 uncertainty_propagate() 自动计算灵敏度并传播输入不确定度。组件名称必须与测量模型的形参名一致且唯一。

代码 
mass <- uncertainty_type_b(
  "mass", estimate = 20, uncertainty = 0.2,
  distribution = "standard"
)
volume <- uncertainty_type_b(
  "volume", estimate = 4, uncertainty = 0.1,
  distribution = "standard"
)

concentration_delta <- uncertainty_propagate(
  model = function(mass, volume) mass / volume,
  components = list(mass, volume),
  method = "delta"
)
concentration_delta

Uncertainty propagation
  Method: delta
  Model estimate: 5
  Standard uncertainty: 0.134629
  95.0% interval: [4.73613, 5.26387]
代码 
concentration_mc <- uncertainty_propagate(
  model = function(mass, volume) mass / volume,
  components = list(mass, volume),
  method = "monte_carlo",
  simulations = 10000,
  seed = 20260901
)
concentration_mc

Uncertainty propagation
  Method: monte_carlo
  Model estimate: 5
  Standard uncertainty: 0.13615
  95.0% interval: [4.75089, 5.28508]

delta 方法适合输入不确定度较小且模型在估计值附近近似线性的情况。Monte Carlo 可用于输出分布明显偏斜或需要非对称覆盖区间的场景；正式报告应保存模拟次数、随机种子、分布和相关结构。

代码 
plot(concentration_delta, type = "contribution")
代码 
plot(concentration_mc, type = "distribution")

5.1.9 计量溯源链累计 uncertainty_traceability()

uncertainty_traceability() 按阶段记录新增分量，并返回每个阶段的累计预算。阶段名称应与质量体系中的校准链节点保持一致。

代码 
trace <- uncertainty_traceability(
  stages = list(
    reference = list(certificate),
    assignment = list(repeatability),
    release = list(homogeneity_component$component)
  ),
  value = 100,
  coverage = 0.95,
  k = 2
)

5.2 分析案例

5.2.1 CLSI EP29-A 附录 A：Type B 限值转换

CLSI EP29-A 附录 A 比较矩形、三角形和正态分布下，将 90～180 的限值区间转换为标准不确定度的结果，并给出称量规格、天平线性和重复性案例。以下使用 uncertainty_type_b() 和 uncertainty_combine() 重新计算；正态案例按标准原文的“±3 个标准差”解释，设置 coverage = 0.9973。

代码 
ep29_a_rectangular <- uncertainty_type_b(
  "EP29 rectangular limits", estimate = 135,
  lower = 90, upper = 180, distribution = "rectangular"
)

ep29_a_triangular <- uncertainty_type_b(
  "EP29 triangular limits", estimate = 135,
  lower = 90, upper = 180, distribution = "triangular"
)

ep29_a_normal <- uncertainty_type_b(
  "EP29 normal limits", estimate = 135,
  lower = 90, upper = 180, distribution = "normal",
  coverage = 0.9973
)

ep29_a_weighing <- uncertainty_type_b(
  "EP29 weighing specification", estimate = 156,
  lower = 155, upper = 157, distribution = "rectangular"
)

ep29_a_linearity <- lapply(
  1:2,
  function(i) uncertainty_type_b(
    paste0("linearity ", i), estimate = 0,
    uncertainty = 0.02 / sqrt(6), distribution = "standard"
  )
)

ep29_a_repeatability <- lapply(
  1:2,
  function(i) uncertainty_type_b(
    paste0("repeatability ", i), estimate = 0,
    uncertainty = 0.01 / 3, distribution = "standard"
  )
)

ep29_a_balance <- uncertainty_combine(
  ep29_a_linearity[[1]], ep29_a_linearity[[2]],
  ep29_a_repeatability[[1]], ep29_a_repeatability[[2]],
  k = 1
)

ep29_a_tight <- uncertainty_combine(
  uncertainty_type_b(
    "EP29 tight specification", estimate = 156,
    lower = 155.9, upper = 156.1, distribution = "rectangular"
  ),
  uncertainty_type_b(
    "EP29 rounded balance", estimate = 0,
    uncertainty = 0.013, distribution = "standard"
  ),
  k = 1
)

从标准 PDF 附录 A 的原文结果检查表读取标准值，并逐项合并比较：

5.2.7 CLSI EP29-A Example 11：线性回归预测方程

Example 11 用 A1C 预测 eAG，测量模型为 \(eAG = \alpha + \beta A1C + \epsilon\)。以下使用 uncertainty_propagate() 传播截距、斜率、A1C 测量值和预测误差的不确定度，并按标准 Table 4 的参数在 A1C = 7% 处计算三个情景。

代码 
ep29_ex11_make <- function(relative_a1c_u) {
  a1c <- 7
  uncertainty_propagate(
    model = function(alpha, beta, A1C, epsilon) {
      alpha + beta * A1C + epsilon
    },
    components = list(
      uncertainty_type_b("alpha", estimate = -46.6, uncertainty = 3.8,
                         distribution = "standard"),
      uncertainty_type_b("beta", estimate = 28.7, uncertainty = 0.6,
                         distribution = "standard"),
      uncertainty_type_b("A1C", estimate = a1c,
                         uncertainty = relative_a1c_u * a1c,
                         distribution = "standard"),
      uncertainty_type_b("epsilon", estimate = 0,
                         uncertainty = 2.21 * a1c,
                         distribution = "standard")
    )
  )
}
ep29_ex11_results <- lapply(c(0, 0.02, 0.05), ep29_ex11_make)

5.2.8.3 附录 C：定值不确定度合成

工作校准品证书和复溶信息先转换为 B 类组件，赋值重复性由 uncertainty_type_a() 估计，最终使用 uncertainty_combine() 合成相对和绝对不确定度。

代码 
yyt1709_assignment <- read_csv(
  "./data/005-不确定度分析/std-yyt1709-assignment.csv",
  show_col_types = FALSE
)

yyt1709_assignment_u <- uncertainty_type_a(
  yyt1709_assignment$result,
  name = "赋值重复性",
  quantity = "mean",
  relative = TRUE
)

yyt1709_assigned_mean <- mean(yyt1709_assignment$result)

yyt1709_working_calibration <- uncertainty_type_b(
  "工作校准品",
  estimate = 178.06,
  uncertainty = 6.01,
  distribution = "standard",
  k = 2,
  relative = TRUE
)
yyt1709_reconstitution_1 <- uncertainty_type_b(
  "工作校准品复溶",
  estimate = 1,
  uncertainty = 0.00003 / (sqrt(3) * 0.99758),
  distribution = "standard",
  k = 1,
  relative = TRUE
)
yyt1709_reconstitution_2 <- uncertainty_type_b(
  "产品校准品复溶",
  estimate = 1,
  uncertainty = 0.01 / sqrt(3),
  distribution = "standard",
  k = 1,
  relative = TRUE
)

yyt1709_reconstitution <- uncertainty_combine(
  yyt1709_reconstitution_1,
  yyt1709_reconstitution_2,
  k = 1
)
yyt1709_characterization_budget <- uncertainty_combine(
  yyt1709_working_calibration,
  yyt1709_assignment_u,
  yyt1709_reconstitution_1,
  yyt1709_reconstitution_2,
  value = yyt1709_assigned_mean,
  coverage = 0.95,
  k = 2
)

这里传入的 uncertainty 已是标准不确定度，因此使用 distribution = "standard" 表示函数不再进行分布换算。两个式子中的 sqrt(3) 用于将矩形分布的允许半宽换算为标准不确定度；第一项中的 0.99758 是实际称量质量，用于把绝对称量误差转换为相对误差，不是分布参数。
