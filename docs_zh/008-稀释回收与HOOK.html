8  稀释回收与HOOK

本文演示如何使用 ivdtools 包分析稀释回收、加标回收和高剂量钩状效应。稀释回收用于评价稀释后结果能否按稀释倍数还原，加标回收用于评价加入分析物后的实测增量，高剂量钩状效应用于识别高浓度样本信号下降并重新进入测量区间的风险。

三个分析路径都涉及浓度或响应的变化，但输入数据、分母和结论不同：

分析路径 主要输入 主要返回结果
稀释回收 原样编号、测量结果、稀释倍数及可选赋值 靶值、稀释校正浓度、单样本回收率及跨样本区间
加标回收 分析物加标与等体积溶剂对照结果、理论加入浓度 观测增量、单样本及跨样本回收率
高剂量钩状效应 已知浓度、原始响应、ULoQ 及可选试验序列 浓度水平汇总、钩状效应界限和未观察到钩状效应时的下限
重要使用边界

本章函数只进行数据汇总、回收率计算、区间估计和钩状效应界限识别，不内置接受标准，也不自动建立或验证扩展测量区间（EMI）。稀释液、稀释倍数、加标材料、样本类型、ULoQ、最高试验浓度和允许回收范围必须在查看结果前确定。

代码 
library(ivdtools)
library(readr)

8.1 主要函数

函数 用途 返回值
dilution_recovery() 计算稀释靶值、校正浓度和回收率 dilution_recovery 对象
spike_concentration() 按质量平衡计算加标后的理论浓度 spike_concentration 数据框
spike_recovery() 计算分析物加标相对溶剂对照的回收率 spike_recovery 对象
hook_effect() 汇总高浓度响应并识别钩状效应界限 hook_effect 对象

8.1.1 稀释回收 dilution_recovery()

调用形式

代码 
dilution_recovery(
  data,
  sample,
  result,
  dilution_factor,
  assigned = NULL,
  diluent_value = 0,
  conf.level = 0.95
)

plot(x, type = c("recovery", "summary", "observed"))

参数

参数 说明
data 长格式数据框，每行是一项测量结果。
sample 原样编号列的列名。
result 数值型测量结果列的列名。
dilution_factor 数值型稀释倍数列的列名；未稀释为 1，1/2 稀释为 2。
assigned 可选的原样赋值列；省略时以每份样本未稀释结果的均值作为原样浓度。
diluent_value 稀释液中的分析物浓度，默认为 0。
conf.level 同一稀释倍数跨样本平均回收率的置信水平。

返回值

返回 dilution_recovery 类对象。results 保存各“样本 × 稀释倍数”的重复数、均值、SD、CV、原样赋值、靶值、稀释校正浓度和回收率；summary 保存各稀释倍数的样本数、平均回收率、SD、SE、自由度和置信区间；data 与 excluded 分别保存进入分析的数据和被排除的原始行号。plot() 的 type 可选择单样本回收率、跨样本汇总或实测结果图。

8.1.2 加标浓度 spike_concentration()

调用形式

代码 
spike_concentration(
  sample_concentration,
  sample_volume,
  stock_concentration,
  spike_volume
)

参数

参数 说明
sample_concentration 加标前样本浓度。
sample_volume 参加混合的样本体积。
stock_concentration 加标材料浓度。
spike_volume 加入的加标材料体积。

四个参数均接受有限数值向量，并按 R 的普通向量循环规则配对；浓度单位和体积单位必须分别保持一致。

返回值

返回 spike_concentration 类数据框，包含输入浓度和体积、total_volume、spike_fraction、 added_concentration 以及混合后的 final_concentration。

8.1.3 加标回收 spike_recovery()

调用形式

代码 
spike_recovery(
  data,
  sample,
  result,
  condition,
  analyte_level,
  solvent_level,
  added_concentration = NULL,
  sample_volume = NULL,
  stock_concentration = NULL,
  spike_volume = NULL,
  conf.level = 0.95
)

plot(x)

参数

参数 说明
data 长格式加标试验数据框。
sample 样本编号列的列名。
result 数值型测量结果列的列名。
condition 区分分析物加标与溶剂对照的条件列。
analyte_level、solvent_level 分别标识分析物加标和溶剂对照条件的取值。
added_concentration 最终混合液中的理论加入浓度，可为单个数值或数据列；提供后不再由体积计算。
sample_volume、 stock_concentration、 spike_volume 未提供 added_concentration 时用于计算理论加入浓度，可为单个数值或数据列。
conf.level 跨样本平均回收率的置信水平。

返回值

返回 spike_recovery 类对象。results 保存每份样本两个条件的重复数、均值和 SD，以及观测增量、理论加入浓度和回收率；summary 保存跨样本平均回收率、SD、SE、自由度和置信区间；data 与 excluded 保存分析数据和被排除行号；plot() 返回各样本回收率图。

8.1.4 高剂量钩状效应 hook_effect()

调用形式

代码 
hook_effect(
  data,
  concentration,
  response,
  series = NULL,
  uloq,
  uloq_response = NULL,
  conf.level = 0.95
)

plot(x)

参数

参数 说明
data 含已知浓度和原始响应的数据框。
concentration 数值型已知浓度列的列名。
response 数值型原始响应列的列名，不能使用仪器截断后的报告浓度替代。
series 可选的独立钩状效应试验序列列。
uloq 分析测量区间上限浓度。
uloq_response 可选的 ULoQ 原始响应；省略时每个序列必须包含 concentration == uloq 的记录。
conf.level 各浓度平均原始响应的置信水平。

返回值

返回 hook_effect 类对象。level_summary 保存各“序列 × 浓度”的重复数、均值、SD、CV、SE 和置信区间；results 保存 ULoQ 响应、钩状效应界限、首次回落至 ULoQ 响应范围内的浓度以及最高试验浓度；minimum_hook_concentration 为所有序列中最保守的界限；data 与 excluded 保存分析数据和被排除行号。函数不在相邻浓度之间插值。
