11  ROC 曲线与 cutoff

本文演示如何使用 ivdtools 评价一个定量标记物区分目标状态的能力，并在明确判定方向后查看候选 cutoff。ROC 曲线描述一组阈值下灵敏度与特异度的权衡，AUC 概括整个经验 ROC，cutoff 则对应一个具体决策点，三者回答的问题不同。

重要使用边界

ROC 结论以参考状态正确、研究对象具有代表性以及阳性定义正确为前提。ivdtools 当前提供经验 ROC、梯形 AUC、Hanley–McNeil 单曲线标准误和两种样本内 cutoff 准则；不提供部分 AUC、固定灵敏度或特异度下的区间、配对 ROC 检验、cutoff 的重抽样不确定度、样本量设计或外部验证。

函数会根据阳性组和阴性组的标记物均值自动选择 geq 或 leq 方向，没有单独的方向参数。正式分析必须核对自动方向是否符合预设临床含义。样本内“最优” cutoff 具有选择偏倚，不能直接解释为独立人群的验证结果或标准推荐阈值。

11.1.1 连续参考变量转换 continuous_to_binary()

代码 
continuous_to_binary(data, cols, cutoff)
参数 说明
data 数据框。
cols 一个或多个需要转换的数值列名。
cutoff 有限数值；长度为 1 时循环用于全部列，否则必须与 cols 等长。

对第 \(j\) 个变量使用

\[ B_{ij}=I(X_{ij}\ge c_j). \]

函数保留原列并新增 <变量>_binary。它固定把“等于 cutoff”划入 1，不支持 <= 方向；因此只有当该二分定义已经由方案或外部参考确定时才应使用。不要为了提高 ROC 表现而在同一数据中反复寻找参考变量的二分阈值。

返回保留原列并新增 <变量>_binary 列的数据框。

11.1.2 建立分析对象 roc()

代码 
roc(data, cols, reference, id = NULL, positive = NULL)
参数 说明
data 数据框。
cols 一个或多个数值型标记物列名。
reference 单个参考状态列名；可为数值 0/1、二水平因子或二取值字符。
id 可选受试者标识列；仅用于报告重复 ID，不会自动去重。
positive 因子或字符参考列的阳性水平；省略时取排序后的最后一个水平。数值 0/1 省略时以 1 为阳性。

roc() 同时要求 reference 和全部 cols 为有限完整值。设完整性指示为

\[ R_i=I(Y_i\text{ 完整})\prod_{j=1}^{p}I(X_{ij}\text{ 有限且完整}), \]

只有 \(R_i=1\) 的受试者进入对象。即使以后只对一个 cols 子集调用 auc()，分析样本仍是建对象时由全部标记物确定的共同完整病例。若希望每个标记物使用各自完整病例，应分别建立对象。

对标记物 \(X_j\)，源码比较两组均值：

\[ \bar X_{j,+}\ge\bar X_{j,-}\Rightarrow \widehat Y=I(X_j\ge c)\quad(\texttt{geq}), \]

\[ \bar X_{j,+}<\bar X_{j,-}\Rightarrow \widehat Y=I(X_j\le c)\quad(\texttt{leq}). \]

这是计算方向，不是临床方向验证。一个受极端值影响的组均值可能选择错误方向；必须查看 col_direction 并与方案核对。

主要字段包括 n、n_pos、n_neg、n_total、cols_values、reference_binary、col_direction、print，以及后续逐步写入的 describe、auc_list、auc_table、cutoff_table 和 mlr_results。

返回 roc 类对象，保存共同完整病例、参考状态、标记物值和自动方向，并逐步写入后续分析槽。

11.1.3 描述统计 describe()

返回描述统计数据框；数值列包含样本量、均值、SD、分位数和范围，分类列包含频数和百分比。

代码 
describe(x, cols = NULL, digits = 4L)

cols=NULL 时描述原数据中除显式 ID 外的所有列，而不只是 ROC 标记物。数值列给出 \(n\)、均值、SD、最小值、四分位数和最大值；因子、字符以及参考列给出频数和百分比。当前实现不会按阳性/阴性分别汇总标记物，因此两组分布差异需另行制表或绘图。

11.1.4 AUC auc()

代码 
auc(x, cols = NULL)

经验 ROC 在所有不同观测值和两端的 \(\pm\infty\) 阈值上计算，再按假阳性率 \(\mathrm{FPR}=1-\mathrm{Sp}\) 对灵敏度作梯形积分。等价的秩解释为

\[ \widehat A= \frac{1}{n_+n_-} \sum_{i:Y_i=1}\sum_{j:Y_j=0} \left[I(X_i>X_j)+\frac12I(X_i=X_j)\right], \]

其中低值代表阳性时按反向次序理解。AUC 是随机抽取一个阳性和一个阴性时，标记物按所选方向正确排序二者的概率估计；它不等于某 cutoff 下的准确率。

当前标准误采用 Hanley–McNeil 近似。令

\[ Q_1=\frac{\widehat A}{2-\widehat A},\qquad Q_2=\frac{2\widehat A^2}{1+\widehat A}, \]

则

\[ \operatorname{SE}(\widehat A)= \sqrt{\frac{ \widehat A(1-\widehat A) (n_+-1)(Q_1-\widehat A^2) (n_--1)(Q_2-\widehat A^2)} {n_+n_-}}. \]

95% CI 为 \(\widehat A\pm1.96\,\operatorname{SE}(\widehat A)\)，并截断到 \([0,1]\)。当 AUC 恰为 0 或 1 时当前实现返回 NA 标准误和区间，而不是精确区间或重抽样区间。

返回更新后的 roc 对象；auc_list 保存各标记物 ROC 点、AUC、标准误和区间，auc_table 为汇总表。

11.1.5 cutoff 分析 cutoff()

代码 
cutoff(x, cols = NULL)

必须先执行 auc()。对 geq 方向，预测阳性定义为 \(X_i\ge c\)；对 leq 方向定义为 \(X_i\le c\)。每个候选阈值计算

\[ \mathrm{Se}=\frac{TP}{TP+FN},\qquad \mathrm{Sp}=\frac{TN}{TN+FP}, \]

\[ \mathrm{PPV}=\frac{TP}{TP+FP},\qquad \mathrm{NPV}=\frac{TN}{TN+FN},\qquad \mathrm{Accuracy}=\frac{TP+TN}{N}. \]

表中的 precision 指 PPV。两种自动选择准则为

\[ J(c)=\mathrm{Se}(c)+\mathrm{Sp}(c)-1 \]

的最大值（Youden），以及

\[ d(c)=\sqrt{[1-\mathrm{Se}(c)]^2+[1-\mathrm{Sp}(c)]^2} \]

的最小值（Corner）。候选集合是实际观测值和两个无穷端点；无穷端点用于补全 ROC，但不会作为报告的最优 cutoff。若多个有限阈值并列，源码按内部阈值顺序选第一个：geq 为从高到低，leq 为从低到高。因此自动结果还包含一个确定性的并列处理规则。

警告观测值 cutoff 与开区间 cutoff

EP24 的手工表通常把 cutoff 写成相邻观测值之间的开区间。ivdtools 把观测值本身作为阈值，且等号归入阳性侧。报告时必须同时给出判定式，例如“结果 \(\ge9.5\) 为阳性”，不能只写 “cutoff 9.5”，也不能把开区间端点和实际判定阈值混为一谈。

返回更新后的 roc 对象；cutoff_table 保存候选阈值、混淆矩阵、诊断指标及两个选择准则的结果。

11.1.6 绘图与汇总 plot()、summary()

代码 
plot(x, curves = NULL, cutpoint = NULL,
     type = c("roc", "cutoff"))
summary(x)
  • curves=NULL 默认选择全部原始标记物；curves="all" 选择全部原始标记物和已保存 MLR；也可用字符向量混合指定二者，例如 c("x1", "combined")。
  • type="roc" 绘制灵敏度对 \(1-\mathrm{Sp}\)；选择原始标记物时需要先执行 auc()。cutpoint 可取 "Youden"、"Corner" 或 "all"，且需先执行 cutoff()；它只标注所选原始标记物。
  • type="cutoff" 绘制一个原始标记物的灵敏度和特异度随有限阈值变化，只允许在 curves 中指定一个原始标记物，暂不支持 MLR 模型概率。
  • summary() 只汇总对象中已经执行的分析，不会自动补做 describe()、auc() 或 cutoff()。

plot() 不可见地返回 ggplot 对象；summary() 打印并不可见地返回输入的 roc 对象。

11.2.2 CLSI EP24-A2 示例 1：经验 ROC 与阈值区间

EP24 的表 2 把判定点写在相邻观测值之间，而 ivdtools 用“\(\ge\)”并选择实际观测值 9.5；这是阈值表示方式的差异。
