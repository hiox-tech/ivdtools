18  瓶间差分析

本文用瓶间差和批次间比较判断物料的均匀性，并演示如何把均匀性结果转化为不确定度分量。显著性检验只说明是否观察到差异，不能单独说明差异是否具有实际影响；最终结论还要结合重复性、目标值和预设可接受标准。

重要使用边界

bottle_anova() 的 F 检验回答“组均值是否完全相同”，不回答差异是否满足产品均匀性限。tukey() 只在整体模型和假设适用时定位成对差异。均匀性不确定度或瓶间 SD 必须由与抽样、测量顺序和重复设计一致的方差模型估计，再与预设技术限比较；不能只凭 p 值放行或拒绝。

分析流程：从瓶间差异到均匀性不确定度

瓶间差（bottle-to-bottle variability）评价同一产品不同瓶（或不同批次）之间测量结果的差异。分析通常分两步：先用 bottle_anova() 检验各瓶（或批次）均值是否有统计学差异，再用方差分量分析把瓶间变异与瓶内变异拆开，判断差异大小是否满足预设的精密度限值。本文演示这两种场景：15 瓶 × 5 次测定的瓶间差，以及不同试剂批测定同一质控品的批间差。

示例数据为确定性的教学数据；统计显著不等于产品不可接受，只能依据方案预先规定的接受限作出判定。

代码 
library(ivdtools)
library(readr)

18.1 主要函数

函数 主要用途 关键输入或输出
bottle_anova() 单因素或嵌套 ANOVA value ~ batch 或 value ~ batch/vial
tukey() Tukey HSD 两两比较与紧凑字母 term 指定效应
precision() / variance() 拆分瓶间/瓶内方差分量 value ~ bottle 单因素

18.1.1 ANOVA、Tukey 与方差分量

代码 
bottle_anova(data, formula, conf.level = 0.95)
tukey(x, term = NULL, conf.level = NULL)

precision(data, value ~ bottle)
variance(x, method = c("auto", "anova", "reml"))
uncertainty_homogeneity(data, unit = "bottle", result = "value", ...)

单因素模型写为

\[ Y_{ij}=\mu+B_i+\varepsilon_{ij}, \]

整体零假设为全部瓶均值相等。经典 F 统计量为

\[ F=\frac{MS_{\mathrm{between}}}{MS_{\mathrm{within}}}. \]

bottle_anova() 删除响应或分组缺失/非有限的行，把右侧变量转为因子，并用 aov() 拟合；嵌套公式如 value ~ lot/vial 展开为 lot 和 lot:vial。对象还给出各组均值 t 区间、Bartlett 方差齐性检验和模型残差 Shapiro–Wilk 检验。这些假设检验同样不能自动选择模型。

tukey() 对指定效应做 Tukey HSD，返回差值、同时区间、调整后 p 值和紧凑字母；默认效应在复杂模型中应核对，必要时显式给出 term。方差分量分析则估计

\[ \sigma_{\mathrm{total}}^2=\sigma_B^2+\sigma_e^2, \]

瓶间 SD 为 \(\sqrt{\sigma_B^2}\)，与 ANOVA p 值是不同尺度的结果。均匀性结论应优先围绕预设最大瓶间变异或其不确定度贡献表达。

bottle_anova() 返回 ANOVA 模型和组间诊断；tukey() 返回两两比较表；precision()/variance() 返回方差分量；uncertainty_homogeneity() 返回均匀性标准不确定度组件。

18.2.1.4 第二步：差异大小是否满足预期

用 precision(value ~ bottle) 把总变异拆成瓶间分量（bottle）与瓶内分量（error）：

代码 
bp <- precision(bottle, value ~ bottle)
bp <- variance(bp)

18.2.2 示例二：不同试剂批测定同一质控品
