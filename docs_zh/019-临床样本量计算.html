19  临床样本量计算

样本量不是脱离研究终点的固定常数，而是由效应大小、变异程度、置信水平、检验效能和研究设计共同决定的规划结果。本文只覆盖 ivdtools 已提供的三类计算：Bland–Altman 一致性限的精度/效能、单比例置信区间半宽，以及单臂比例目标值检验。它们不能直接替代 ROC、精密度方差分量、参考区间或多中心聚类设计的专用样本量论证。

使用前先写清主要终点、分析单位（受试者、样本还是配对结果）、预期比例或差异、允许误差、单双侧方向和无效样本加量。函数返回的是在这些输入假设成立时的理论样本量；若输入的 SD、预期比例或相关性不确定，应对关键参数做敏感性分析并取保守方案。

重要使用边界

三个函数只覆盖三种特定统计问题，返回值不含失访、无效样本、分层最低例数、设计效应或多重终点加量。Bland–Altman 输入中的 delta 是临床可接受界限，不是观察到的 LoA；比例区间方法和单臂检验方向必须预先确定。正式方案应保存全部假设、来源和敏感性分析，而不只报告最终整数。

分析流程：先定义目标，再计算样本量

代码 
library(ivdtools)

19.1 主要函数

样本量计算在研究设计与性能评价方案阶段确定所需样本数或可获得的检验效能。ivdtools 提供三个独立函数，分别对应三类常见问题：

函数 主要用途 求解方向
sample_size_bland_altman() BA 一致性评价 由目标 power 求 n
sample_size_proportion_ci() 单比例置信区间 由目标 half_width 求 n
sample_size_proportion() 单臂目标值检验 由 alpha 和 power 求 n

三个函数都由参数驱动、不需要原始数据文件，并且只计算样本量。它们返回结构化结果，样本量由 result$n 获取，print() 同时显示目标值和实际达到的统计量。示例中的参数（效能、置信水平、允许半宽等）均为教学设定，正式研究必须使用方案规定的参数。样本量向上取整、失访/无效样本加量和分层最低例数应在函数结果之外单独处理。

19.1.1 三类计算的数学目标

代码 
sample_size_bland_altman(
  power = 0.80, mu, sd, delta,
  conf.level = 0.95, agree.level = 0.95,
  method = "lu",
  n.min = 3, n.max = 1e5
)
sample_size_proportion_ci(
  p, half_width, conf.level = 0.95,
  interval = c("two.sided", "lower", "upper"),
  method = "wilson", n.max = 1e6
)
sample_size_proportion(
  p0, p1, alpha = 0.05, power = 0.80,
  alternative = c("greater", "less", "two.sided"),
  test = "exact", power_method = "binomial", n.max = 1e6
)

Bland–Altman 函数假定差值近似正态，目标 LoA 为

\[ \mu\pm z_{(1+\gamma)/2}\sigma, \]

其中 \(\gamma=\) agree.level。函数按 Lu 等方法用非中心 t 分布计算“两侧 LoA 置信界均落入临床界限 \(\pm\delta\)”的效能，再搜索达到目标效能的最小整数。必须满足 \(\delta>|\mu|+z_{(1+\gamma)/2}\sigma\)；否则总体 LoA 本身已经超出临床界限，函数直接报错。

单比例区间的目标是：双侧区间控制总宽度的一半，单侧区间控制预期比例到相应置信限的距离，

\[ \frac{U-L}{2}\le d\quad\text{（双侧）},\qquad \widehat p-L\le d\ \text{或}\ U-\widehat p\le d\quad\text{（单侧）}. \]

规划宽度直接在预期比例 \(p\) 处计算，避免先把 \(np\) 四舍五入后在小样本、高比例情形产生 \(\widehat p=1\) 和零标准误。这个双侧定义与 SAS 的 HALFWIDTH 及 PASS 总宽度的一半一致；对于 Wilson、Clopper–Pearson 等非对称区间，不再把较长一侧误当成总宽度的一半。函数搜索满足半宽约束的第一个整数，并在最终 \(n\) 下枚举整数成功数，报告 actual_coverage 和 actual_alpha。

单臂函数检验 \(H_0:p=p_0\) 与由 alternative 指定的备择。test 决定拒绝域，power_method 决定样本量采用连续正态近似还是离散二项枚举。无论采用哪种规划方法，函数都会对最终整数样本量按二项分布核算 actual_alpha 和 achieved_power。二项设计还同时要求实际 α 不超过目标 α，避免近似检验因 α 膨胀而得到虚假的小样本量。

三个函数均返回结构化样本量结果；result$n 为向上取整后的样本量，并保存目标参数、实际覆盖度、实际 α、达到的效能及搜索边界。

19.2 分析案例

19.2.1 示例一：Bland–Altman 一致性评价的样本量

代码 
n_ba <- sample_size_bland_altman(
  power = 0.80,
  mu = 0.2,
  sd = 1,
  delta = 2.5
)
print(n_ba)

  Mean difference   : 0.2000
  SD of differences : 1.0000
  Clinical limit    : 2.5000
  Confidence level  : 0.9500
  Agreement level   : 0.9500
  Sample size (n)   : 201
  Target power      : 0.800000
  Achieved power    : 0.800300

在平均差异 mu = 0.2、差异 SD sd = 1、临床一致性限 delta = 2.5 的设定下，达到 80% 效能约需 201 对样本。

mu 为平均差异，sd 为差异标准差（>0），delta 为临床可接受的一致性限（>0）。conf.level 是一致性限置信区间的置信水平，agree.level 是 LoA 的覆盖度，两者是不同层次——前者影响估计的可靠性，后者决定 LoA 本身的宽度。

n_pci <- sample_size_proportion_ci(p = 0.3, half_width = 0.05)
print(n_pci)

对预期比例 p = 0.3，要使 95% Wilson 置信区间的总宽度不超过 0.10（半宽不超过 0.05），约需 320 例。结果同时给出规划区间、实际覆盖率和实际 α。

p 为预期比例（必须给定，0≤p≤1；边界值主要用于单侧精确区间），half_width 对双侧区间表示总宽度的一半，对单侧区间表示 p 到相应置信限的距离。method 可选 7 种置信区间方法（默认 "wilson"，另有 "wald"、"wald-cc"、"agresti-coull"、"jeffreys"、"wilson-cc"、"clopper-pearson"），方法选择影响所需样本量，应在方案中说明。

  p1 = 0.35,
  alpha = 0.05,
  power = 0.8,
  alternative = "greater",
  test = "exact",
  power_method = "binomial"
)
print(n_sp)

  Power calculation     : Binomial enumeration

在 p0 = 0.2（目标/零假设比例）与 p1 = 0.35（预期比例）、单侧 α = 0.05、效能 0.80 的设定下，精确二项设计需要 56 例；实际 α 和实际效能分别由结果中的 actual_alpha 和 achieved_power 给出。

alternative 可取 "greater"（此时要求 p1 > p0）、"less" 或 "two.sided"。test 选择精确、Score、Wald 或其他区间反演拒绝域；power_method 独立选择 "binomial" 或 "normal"。正态效能可用于 Exact、Score、Wald 及后二者的连续性校正版本；对无限总体，Exact 与 Score 的正态近似规划公式相同，但最终离散拒绝域仍由 test 决定。

19.2.6 单比例目标值检验：SAS、PASS 多参数对照

软件选项与包参数对应如下。

SAS/PASS 选项 ivdtools 参数 含义
SAS TEST=Z VAREST=NULL；PASS Z-test using S(P0) test = "score" α 项使用 \(p_0\) 方差

19.2.7 CMDE《体外诊断试剂临床试验技术指导原则》附录案例一：有临床可接受标准的目标值法

附录采用正态近似公式

\[ n=\frac{\left[Z_{1-\alpha/2}\sqrt{P_0(1-P_0)}+ Z_{1-\beta}\sqrt{P_T(1-P_T)}\right]^2}{(P_T-P_0)^2}. \]

案例设双侧 \(\alpha=0.05\)、效能 \(1-\beta=0.80\)。阳性符合率的可接受标准/预期值为 85%/90%，阴性符合率为 90%/94%。附录用 \(Z_{0.975}=1.96\)、\(Z_{0.80}=0.84\)，报告阳性组 362 例、阴性组 388 例，合计 750 例；按 10% 脱落剔除率加量后至少入组 834 例。

sample_size_proportion(test="score", power_method="normal") 执行同一连续正态近似。包使用未舍入的正态分位数，并将理论样本量向上取整；随后另外按离散二项拒绝域核算实际 α 和实际效能。

代码 
cmde_target_value <- data.frame(
  group = c("阳性组", "阴性组"),
  p0 = c(0.85, 0.90),
  p1 = c(0.90, 0.94),
  cmde_n = c(362L, 388L)
)

cmde_target_results <- lapply(
  seq_len(nrow(cmde_target_value)),
  function(i) {
    sample_size_proportion(
      p0 = cmde_target_value$p0[i],
      p1 = cmde_target_value$p1[i],
      alpha = 0.05,
      power = 0.80,
      alternative = "two.sided",
      test = "score",
      power_method = "normal"
    )
  }
)

19.2.8 CMDE《体外诊断试剂临床试验技术指导原则》附录案例二：只要求置信区间精度的允许误差法

附录公式为

\[ n=\frac{Z_{1-\alpha/2}^2P(1-P)}{\Delta^2}. \]

灵敏度预期为 85%、特异度预期为 90%，允许误差 \(\Delta=0.05\)。该公式对应 sample_size_proportion_ci(method = "wald")；包使用精确的 qnorm(0.975)，并把样本量向上取整为满足半宽要求的最小整数。

代码 
cmde_ci_precision <- data.frame(
  group = c("阳性组（灵敏度）", "阴性组（特异度）"),
  p = c(0.85, 0.90),
  cmde_n = c(196L, 138L)
)
cmde_ci_precision$ivdtools_n <- vapply(
  cmde_ci_precision$p,
  function(p) sample_size_proportion_ci(
    p = p, half_width = 0.05, conf.level = 0.95, method = "wald"
  )$n,
  integer(1)
)

阴性组包结果为 139，而附录报告 138。差异来自两个细节：附录代入近似值 1.96 后把 138.30 报为 138，包使用精确分位数并向上取整。附录据 334 例进一步报告 10% 加量后 371 例；若“至少入组”按保守整数处理，包的 335 个可分析病例应取 \(\lceil335/0.90\rceil=373\)。这不是置信区间方法差异，而是分位数精度和整数取整规则差异。

当预期比例接近 100% 时，指导原则也提醒正态近似可能不适用。此时可以用 sample_size_proportion_ci(method = "clopper-pearson") 等方法做敏感性分析，但结果属于改变区间方法后的补充分析，不能标成附件 Wald 公式的复算。
