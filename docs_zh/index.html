体外诊断试剂评估数据分析工具

作者

hiox-tech

发布于

2026年9月11日

欢迎

本书是 R 包 ivdtools 的可执行、可审计使用指引，服务于 IVD 从业者、统计人员和刚接触 R 的读者。它覆盖从数据进入项目到结果导出、实验情境以及包源码实际采用的统计算法等内容。

重要使用边界

本书用于统计工作流教学和实现复核，不能替代现行法规或标准文件。

读者路线

  • 初学者依次阅读第一部分和第二部分，再按任务进入函数章节。
  • 有经验的分析者可直接查阅函数签名、对象字段和边界行为。

获取帮助

代码 
help(mcr,"ivdtools")

查看/下载完整函数手册和本帮助文档可访问项目主页。

版本与引用

代码 
version <- packageVersion("ivdtools")
version
[1] '0.2.5'

软件可引用为：hiox-tech (2026). ivdtools: Statistical Tools for Evaluation of in Vitro Diagnostic Reagents. R package version 0.2.5, https://github.com/hiox-tech/ivdtools.
